# TAOCP 攻克计划 (MMIX & C++)

本项目致力于深入学习 Donald Knuth 的《计算机程序设计艺术》（The Art of Computer Programming），通过 MMIX 汇编语言与 C++ 实现书中的算法与练习。

## 目录结构说明
- **docs/**: 存放参考文档与处理后的学习笔记
- **src/mmix/**: MMIX 汇编源代码实现
- **src/cpp/**: C++ 算法实现与性能基准测试
- **tests/**: 针对 MMIX 和 C++ 代码的测试套件
- **tools/**: 开发辅助脚本与 MMIX 模拟器工具链

## 目标
1. 完成 TAOCP 中关键算法的 MMIX 汇编实现，理解底层机器指令。
2. 使用现代 C++ (C++17/20+) 对算法进行高效重构。
3. 建立完整的单元测试，验证算法的正确性。
